# 提交清单

1. 填写个人简介、作者姓名与仓库链接，删除全部待填提示。Markdown 和 Word 内容保持一致。
2. 核对真实参与情况，不使用未经确认的经历或能力承诺。
3. 运行 `python tools/preflight.py` 检查代码，再运行 `python tools/preflight.py --submission` 检查报名准备状态。
4. 自己从解压目录运行演示，修改一条分类规则并解释结果。
5. 查看 Word 分页及 Excel 结果；公开仓库与包含个人资料的报名包分开整理。
6. 人工检查所有待公开文件及 Git 历史，自动扫描通过不代表没有隐私信息。
7. 对照招新原通知确认收件地址、截止时间和附件命名。本项目不替你确认这些外部信息。
8. 将压缩包改名为原通知要求的格式，确认包含最终源码和重新生成的演示结果。

## 邮件内容要点

写明姓名、学号、专业、项目名称、仓库地址和附件说明。简要说明项目功能、本人参与及 AI 工具使用情况。不要直接照抄示例经历。
