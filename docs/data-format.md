# 数据字段与口径

输入为 xlsx，前 80 行内需要找到交易时间与金额表头。必要字段：交易时间、金额(元)、收/支、当前状态。分类还使用交易类型、交易对方和商品。日期支持 Excel datetime 和 YYYY-MM-DD HH:MM:SS 文本。

支出金额为原付款额。已全额退款扣除全部金额；已退款(¥20.00) 或已退款¥20.00 扣除指定金额。退款金额不能大于原付款，含糊状态需要人工处理。收入类型包含退款时不计入普通收入。

原始明细保留付款金额，统计副本使用净额。消费口径将退款归于原消费日期；现金流差额按实际流水日期统计。跨期退款需同时查看两者，不能将它们称为账户余额。

日期区间使用左闭右开。指定起止日期时包含零消费日；未指定边界从记录推断。不支持自动合并多个账单或去重，重复导入须自行避免。

分类规则按顺序匹配。超市等综合商户可能混有非餐饮，需要人工校正；充值仅提示，不自动扣除后续消费。演示数据为合成样例，不能证明对所有真实账单格式都适用。
