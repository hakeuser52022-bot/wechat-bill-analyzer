# 微信账单分析器项目讲解

## 应用场景

把流水转换成分类报告，并明确退款、日期窗口和预算假设，帮助使用者检查自己的开销。

## 实现过程

读取与校验字段 → 计算退款净额 → 关键词分类 → 按日期统计 → 输出报告与预算。
四个入口共享净额和餐饮判断，避免不同模块使用互相矛盾的规则。

## 演示顺序

1. 安装 requirements.txt 中的依赖，运行 tools/run_demo.py。
2. 打开 examples/output/demo_report.xlsx，说明流水、退款、净支出和收入的区别。
3. 查看 docs/demo.md 中的预算，解释外卖替代午餐的假设。
4. 修改 examples/rules.example.json 中一条规则，用 --rules 重新运行分类。
5. 运行 tests/test_core.py，解释 39 元支出退 20 元为何保留 19 元。

## 已知限制

关键词分类可能出错，笔均餐费不一定等于每餐成本；无样本时不生成完整预算。现金流与消费归属口径在跨期退款时不同。详见 [README](../README.md) 和 [修订记录](dev-log.md)。
